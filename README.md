# 💪 ForgeFit — Get Jacked. Every Morning.

AI-powered morning workout app built with Kotlin + Jetpack Compose + Claude API.

## Features
- 🤖 AI Workout Generator (Claude Sonnet 4.6)
- 🔥 Jacked Score™ gamification system
- ⏱️ Active workout mode with rest timers
- 📈 Progressive overload tracking (coming soon)
- 🌅 Morning routine streak system

## Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose + Material 3
- **DI**: Hilt
- **DB**: Room
- **Network**: Retrofit + OkHttp → Anthropic Claude API
- **Architecture**: MVVM + Repository pattern
- **CI**: GitHub Actions → APK artifact

## Setup
1. Clone the repo
2. Add `CLAUDE_API_KEY` to your GitHub repo secrets
3. Push to `main` → GitHub Actions builds the APK automatically
